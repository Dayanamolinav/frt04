## Requisitos

Antes de ejecutar el proyecto, debes tener instalado:

- Node.js
- npm

Puedes verificar que estén instalados con:

```bash
node -v
npm -v

Cada vez que descargues o clones el proyecto en un computador nuevo, primero debes ejecutar:
npm install
y luego:
npm run dev
